\# 🥤 음료수 관리 프로젝트 (Drink Tracker)



팀원별 음료수 구매 일시 및 개인별 소비 수량을 기록하고 관리하는 프로젝트입니다.



\---



\## 📌 주요 기능

\- \*\*음료수 구매 기록\*\*: 구매자, 음료 종류, 수량, 구매 일시 등록

\- \*\*내역 조회\*\*: 전체 구매 및 소비 내역 목록 확인

\- \*\*데이터 저장\*\*: `drink\_records.json` 파일에 자동 기록 및 연동
